# 微信小程序（步数桥梁）上线清单

## 原理
微信运动步数只有小程序/原生 App 能读。此伴生小程序负责：读微信运动步数 → 同步到你的 OUTIE 账号（同一套经济：500 步=1 包、日上限 15 包）。H5 游戏本体不变；绑定后页面内计步自动让位给微信步数。

## 你需要做的（一次性）
1. **注册小程序**：mp.weixin.qq.com → 注册小程序（个人主体即可）→ 拿到 AppID。
2. **配置后端密钥**：服务器 `/home/ubuntu/OurVerse/backend/.env` 追加两行：
   ```
   WX_APPID=你的小程序AppID
   WX_SECRET=你的小程序密钥（开发设置里生成）
   ```
   然后重启后端（`bash ourverse.sh`）。
3. **配置合法域名**：小程序后台 → 开发管理 → 服务器域名 → request 合法域名加 `https://our-verse.com`（**域名必须有 ICP 备案**；our-verse.com 若已备案直接填）。
4. **上传小程序**：微信开发者工具 → 导入仓库 `miniprogram/` 目录 → project.config.json 里把 appid 改成你的 → 上传 → 提交审核 → 发布。

## 用户侧使用流程
1. OUTIE 网页「我的」→「绑定微信步数」→ 得到 6 位绑定码（10 分钟有效）。
2. 微信里打开小程序 → 输入绑定码 → 绑定成功。
3. 之后每天打开小程序点「同步微信运动步数」→ 步数按 500 步=1 包自动入账。

## 技术要点
- `code2Session` 换 openid+session_key（服务端），WeRun 数据 AES-128-CBC 解密。
- 绑定关系存 `wxlinks` 集合（openid ↔ identityKey）。
- 步数差量入账：以微信运动当日步数为准减去已计入部分，与页面计步共用日上限；绑定后页面计步接口自动停用，防双源重复。
