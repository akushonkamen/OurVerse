# OUTIE 攻防迭代章程（开发组 × 测评组）

## 对标与验收线（「3A 社交游戏」的操作化定义）
对标：跳一跳 / 羊了个羊 / 旅行青蛙（社交小游戏的体验密度与传播力天花板）。

| 维度 | 达标线（每轮复评） |
|---|---|
| 循环 | 分钟/小时/日/周四层循环全部闭环；日环有正向奖励（不靠愧疚）；小时级有触达手段（推送或等效通知位）；周级内容更新用户可感知 |
| 数值 | 三类画像（通勤 3000 步/周末暴走/不开计步）7 日模拟：既不必然饥饿、也不无限过剩；经济有明确 sink；核心货币不可被无成本刷取 |
| 收集 | 每场活动 ≥5 个可收集目标，其中 ≥1 个条件变体（隐藏/时段/行为解锁）；历史收集永久可展示可穿戴 |
| 社交 | 照片可一键分享出站（带产品回流量）；存在「回访互动」理由（他人互动可被感知） |
| 商业 | 商家能看到自己活动的打卡人数/独立用户/照片数；存在可承兑的到场凭证位 |
| 手感 | 所有核心动作 ≤100ms 视觉+听觉反馈；饿的分级动画覆盖全部状态；无点击无响应死区 |

## 角色
- **测评组（红方）**：三个视角并行进攻——①主策划（循环与数值）②增长官（传播与社交裂变）③破坏者（作弊与边缘路径）+ 交互手感并入①③。产出=攻击清单：缺陷→后果→具体修法（含数值）→成本(S/M/L)→预期指标。
- **开发组（蓝方）**：评审组长（我）分诊排期，S/M 项当轮实现、当轮部署、当轮验证；L 项立案排期并说明理由。
- **评分组**：独立第三方 agent，用上表六维度复评打分，输出分差与残余风险。

## 流程
红方进攻 → 蓝方分诊实现 → 部署 → 评分组复评 → 分差归档 → 下一轮。
未达标的维度自动成为下一轮红方主攻方向。

## R1-R6 蓝方累计动作概览（评分组逐轮核对为真）
- 循环：心情分时衰减（夜间0点）/摸头系统/打卡奖励入账弹窗/评论通知横幅+红点+标题计数/里程碑实体化+5包/邀请归因双向奖励/同场共鸣人脸化
- 数值：三处铸币竞态全部原子化（步数$inc/打卡条件更新/邀请+里程碑条件门）/速率闸/活动限额/organizer不奖/凭证铸造限5张/评论防护/分时衰减
- 收集：点位1-10动态化/残留学生清空/历史收藏可穿可看
- 社交：分享卡三级出口/OG落地页/s:photoId/ref归因闭环（防自邀+上限5）/评论横幅直达/同场名单
- 商业：商家面板（到场/打卡/照片/集齐/核销）/打卡即券/工作台核销/越权修复/宣传照防护
- 手感：四级心情动画/全套音效/防连点/防吞tap/失败态诚实化/无死区

## 终评委可持续性意见（R6）
- 经济：全来源有界+服务端原子执法；唯一结构性观察是活跃用户饲料顺差（调参问题非漏洞）
- 简洁性：复杂度已到顶——「下一个该做的是删和调，不是加」
- 最值得观察的 3 个真实用户指标：①invitedCount 分布（增长环是否真实发生）②凭证核销率（线下商业环唯一硬证据）③饥饿触发率 vs 代币净增量（15 包/日上限要不要调）

## R1 蓝方落地清单（评分组逐项核对为真）
- 循环：心情分时衰减（夜间 0 点）；摸头系统（音效+日 5 次心情+百次彩蛋，服务端持久 /pet/touch）；打卡 +3/+8 入账进弹窗；保命提醒补主打卡路径；收藏馆往期可穿可看
- 数值：步数铸币竞态 $inc 化；单次 600 步+150 步/分速率闸+429；活动限额（进行中≤3/日新建≤2）；organizer 自打不发奖；devSkipGeo 生产强制关；评论 140 字+10 秒频控；领养显式赠 3 包；邀请归因双向 +2 包
- 社交：canvas 分享卡+三级出口；进化弹层分享按钮；/s/:photoId 分享落地页（OG）；照片详情分享出口；ref 归因
- 商业：商家面板（到场人数/打卡次数/照片数/集齐人数）；宣传照越权修复
- 手感：wear/pet 音效；评论空输入提示；feed 面板防吞 tap；计步不可用灰字；IP 定位打卡提示
